Descripción del proyecto

Desarrollo de un sistema web que permite al asesor capturar datos del cliente y montos en un formulario digital, aplicar una fórmula de desglose automático, y generar de forma automática un archivo HTML de respaldo y un PDF enviado por correo electrónico al destinatario definido. Todos los registros se almacenan en base de datos para auditoría. La infraestructura en la nube se cotiza por separado.

Desglose de fases
01
Levantamiento de procesos y entendimiento
Sesión de descubrimiento con el cliente para documentar el proceso actual (as-is) y diseñar el proceso futuro (to-be). Definición de reglas de negocio, campos del formulario y lógica de la fórmula de cálculo.
Entregables
  • Diagrama de proceso actual (as-is)
  • Diagrama de proceso futuro (to-be)
  • Historias de usuario

Desarrollo y pruebas internas

Entregables
